HOW TO PLAY

雨の街を、駆け抜けろ。

移動
A / D（← / → も使用可能）
ジャンプ
W / SPACE / ↑ ・空中でもう一度
急降下
S / ↓ ・空中で押すと素早く着地
刀で攻撃
J / Z ・長押しでも三連撃
高速ダッシュ
K / X / SHIFT ・発動中は無敵
弾き・カウンター
L / C ・敵の攻撃直前に入力
強攻撃
I / V ・気力32で盾を崩す
終ノ一閃
R / O ・残心100%で発動
一時停止
ESC / P

赤い近接予兆は弾きで反撃。橙色の範囲は弾けないので回避。盾兵は強攻撃または背後から崩します。弾き成功後の一撃は威力1.5倍。敵弾は弾き返せます。青い端末で回復と保存。全3ステージのボスを倒すとエンディングです。

ゲームパッド: 左スティック/十字キー=移動、A=跳躍、X=連撃、Y=強攻撃、B=回避、LB=弾き、RB=必殺、START=一時停止。設定でキーを変更できます。保存はこのブラウザ内です。
